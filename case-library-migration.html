Modernizing a Legacy Course Library

Ten customer courses hadn't been touched in four years. I rebuilt them in Rise 360 with current workflows, a consistent template and a practice simulation in every course.

Role
Instructional designer
Timeline
8 weeks
Scope
10 courses
Tools
Rise 360, Storyline 360, LearnUpon
Result
4.95+/5 average rating

The Challenge

Fullbay's customer course library was built in Storyline and hadn't been updated in four years. The visuals looked dated, the interactions felt old, and in places the steps no longer matched how the software actually worked. Customers were learning workflows that had changed.

The Director of L&D asked me to bring the library up to date: modern design, modern interactivity and accurate process content.

My Role

I owned the rebuild from audit to publish: reviewing each legacy course, rewriting outdated content, designing and building the new Rise courses and their simulations, and running reviews. My director set the authoring standards; I built the course template that put those standards into practice.

The Approach

  1. Keep the structure that worked. The legacy courses followed a sound pattern. I kept it, so returning learners would recognize it, and modernized everything inside it.
  2. Build one template, then build ten courses. A shared Rise template meant consistent look, navigation and block patterns, and it made each new course faster to build and easier to update.
  3. Update the content, not just the look. Processes and concepts had changed since the courses were built. Visual polish doesn't matter if the steps are wrong, so I rewrote the process content to match how the software works today.
  4. Put practice in every course. Each course ends with an interactive Storyline simulation embedded in Rise, so learners can practice a real workflow quickly, without risking a mistake in their live account.
  5. Review with everyone who knows the work. Each course went through product SMEs, Support, a peer instructional designer and my director.

The Result

10courses rebuilt in 8 weeks
10practice simulations, one per course
4.95+/5average learner survey rating

Learners and stakeholders said the same thing: the training finally matched their real workflows in the product. The shared template also gives the team one consistent starting point for every future update.

What I'd Do Next

I'd tie each course to the product's release notes, so a change in the software automatically flags the course that teaches it. A library that's accurate on launch day should stay accurate. I'd also add one survey question that measures performance rather than satisfaction: "Could you complete this task in your own account afterward?"
